# Infotecs.Task_1

В данном задании Вам необходимо написать клиент-серверное приложение используя ниже перечисленные технологии
Описание приложения:
Приложение содержит набор статей. У статьи имеется картинка-тизер и набор комментариев, который пользователь может прочитать.
Пользователь может добавить свой комментарий к статье, добавить и удалять статью.
Интерфейс приложения необходимо сделать похожим на макет ниже, но pixel-hunting'ом заниматься не стоит.

#### Технологии

* Dapper
* WPF
* PostgreSQL
* Autofac
* Serilog
* xUnit
* Nelibur.Sword
