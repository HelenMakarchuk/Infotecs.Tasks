# Infotecs.Task_1

Клиент-серверное приложение содержит набор статей. У статьи имеется картинка-тизер и набор комментариев, который пользователь может прочитать. Пользователь может добавить свой комментарий к статье, добавить и удалить статью. Интерфейс приложения необходимо сделать похожим на макет ниже.

#### Технологии

- [ ] Dapper
- [x] WPF
- [x] PostgreSQL
- [x] Autofac
- [x] Serilog
- [x] xUnit
- [ ] Nelibur.Sword
