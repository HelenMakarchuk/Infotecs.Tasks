# Infotecs.Task_2

В данном задании поступил запрос от заказчика на доработку приложения написанного ранее. Заказчик наслушался консультантов и они рассказали ему о новомодных технологиях и способах разработки. Он записал на бумажке слова, которые смог расслышать и теперь просит Вас использовать эти технологии, чтобы сделать приложение "лучше".

#### Технологии

* NHibernate (mapping by code)
* TeamCity
* RabbitMQ

По завершению задания проект должен собираться на TeamCity. Должны запускаться unit-тесты, написанные в предыдущем задании. В артефактах сборки должны быть zip архивы содержащие сервер и клиент с названиями server.zip и client.zip соответственно. RabbitMQ используется для добавления и удаления статьи и комментария, оповещения всех клиентов об изменении (Non-Persistent).
